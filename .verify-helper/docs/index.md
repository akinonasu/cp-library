名前・ファイル名・関数名で検索できます。各ページの **Bundle** で依存ヘッダーを展開し、**Copy** でコピーできます。

Bit Vector やアロケータなど、主にライブラリ内部で使う部品は [補助部品](components/) にまとめています。

ライブラリをコピーするボタンを押すと 1 行目に参照 URL を含むコメント行が自動で添付されるようになっています。

全て爆速で動作することを第一に設計しているため、コード長が非常に長いライブラリが多いことに注意してください。AtCoder では大丈夫だと思いますが、他のコンテストサイトではコード長制限に引っかかる可能性があります。
