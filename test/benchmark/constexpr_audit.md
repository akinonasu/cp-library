# constexpr の全ライブラリ調査

2026-10-22、`fc24b61` の通常版・軽量版を調査しました。既に修正した Taylor shift の階乗表以外に、新しい上限超過は見つかりませんでした。ライブラリの C++ 実装には追加の変更をしていません。

Linux x86_64、GCC 14.2 / Clang 19.1.7、`-std=c++23 -O2 -march=native` で、AtCoder の以下の上限を指定しました。

| 対象 | GCC | Clang |
| --- | --- | --- |
| constexpr の深さ | 1024 | 1024 |
| constexpr のループ回数 | 524288 | — |
| constexpr の演算数・ステップ数 | 2097152 演算 | 524288 ステップ |

| 検証対象 | ファイル数 | 検証方法 |
| --- | ---: | --- |
| 全ライブラリヘッダー | 229 | 各ヘッダーを単独で include |
| 単体テスト | 193 | 利用するテンプレートを実体化 |
| 提出例 | 201 | 実際の API 呼び出しを含めてコンパイル |

合計 1246 回の `-fsyntax-only` コンパイルが全て通過しました。上限はコンパイラ全体の合計ではなく、各定数式の評価に適用されます。

定数表を作る処理は生成元の `.inc` も確認しました。

| 処理 | 主な定数評価 |
| --- | --- |
| FPS | NTT の根、逆スケール、分割済みの階乗表 |
| 高速入出力 | 4 桁の出力表 10000 行、入力用シャッフル表、SIMD 定数 |
| 整数の k 乗根 | 25 × 13 項目の閾値表 |
| 素数篩 | 1155 要素の周期パターン |
| 二項係数 | 既定上限 10000000 の `constinit` 初期化。階乗の前計算自体は実行時 |
| その他 | 定数・型の分岐、座標演算、分数演算などの短い constexpr 関数 |

主要な定数表を含む 8 ヘッダーは、サイトに掲載する展開コードでも上限付きコンパイルを実施しました。また、新しい通常 CI のランナーで階乗表・素数篩・k 乗根の既存単体テストを GCC / Clang で実行しました。

再発防止として、通常 CI の単独ヘッダー・単体テスト・サニタイザー・提出例・展開コードのコンパイルに同じ上限を適用しました。設定は `.verify-helper/atcoder_flags.py` と `.verify-helper/config.toml` にあり、設定変更時には影響する検証キャッシュも無効になります。実際に上限を超える C++ 定数式が拒否されることもテストしています。

[全コンパイルの結果・コンパイラ・ソースのハッシュ](results/constexpr_audit/check.json) と [主要な単体テストの実行ログ](results/constexpr_audit/runner.log) を保存しました。任意の利用者定義の constexpr 式や、全てのテンプレート引数の組合せを網羅するものではありません。

再調査は以下で行えます。Boost と ACL のヘッダーに検索パスが必要な環境では `--include` を指定してください。

```sh
python3 test/benchmark/constexpr_audit.py --cxx g++ clang++ --native --jobs 4 --output /tmp/constexpr-audit.json
```
