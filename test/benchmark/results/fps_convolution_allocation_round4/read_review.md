# Read-only candidate reviews

Reviewers: `compose_reversion` and its `profile_scope_review` child. No compilation, edits, or timing were performed for these reviews.

`range_import`: capacity `words` covers offset at most 7 plus the input (at most half the transform length). Range insertion constructs live Mint objects; the later resize constructs and zeroes the remainder. The result is fresh, including when both input arguments are the same vector. All words are live before the FFT writes. A first-stage reduction by p canonicalizes inputs below 2p.

`batch_construct`: every full 64-element batch consists of live Mint objects, all elements are assigned by typed memcpy before range insertion. Full SIMD reads require a complete 64-element block; tails are scalar. Capacity covers all inserted elements and the output pointer is obtained after resizing. Input constness, same-vector multiplication, and padding are preserved.

`tail_store`: the native call uses output A minus d words, d in [0,7]. Saving the first vector of all eight stripes before the body handles the circular overlap at stripe boundaries. For j>=1 an output store reaches only the current and preceding input vector, both already read. All asm input reads precede all output stores. The final heads call reads eight vectors from a separate stack array using input stride 1 and writes using the original stripe stride. Output stays inside the live result vector. The prototype's new optional-output call returns a_ although its real output is the target; the sole caller ignores the pointer. Arbitrary overlap and count zero are outside this helper's contract. A forced-offset guard unit was prepared but not executed because the prototype did not show stable whole-process improvement.

`capacity_1m`: reviewer `profile_scope_review` found no ownership, integer, exception, lifetime, or alias problem within the public length limit. HUGEPAGE covers only complete 2 MiB ranges inside data..data+capacity*sizeof(Mint); POPULATE covers only complete 4 KiB ranges inside the actual used words. Failed extra reserve preserves the empty vector by reserve's strong guarantee, then retries the original size. At len<=2^23, words+262144<=8650775 fits size_t/max_size. All live words and offset slack remain as before.

One portability issue remains in this unadopted measured prototype: owned_end/used_end lack [[maybe_unused]]. If a Linux header omits either MADV_HUGEPAGE or MADV_POPULATE_WRITE, the corresponding variable may trigger an unused-variable Werror. Before any future adoption, mark them maybe_unused or form each expression within its matching #if. The measured GCC14 environment defines both; Mac/Clang exclude this native code. Actual measured sources/patches were retained without editing. Reserve/POPULATE/assign profile values are combined preparation costs; they do not measure the zero loop alone.
