ケース別には退行もあります。距離区間和の `uni_2_00` は 37.93→41.60 ms、Aho–Corasick の `random_00` は 33.05→35.14 ms、Point Set Range Frequency の `medium_00` は 10.08→10.60 ms でした。表の最大値の改善だけで全ケースが速くなるとは限りません。

共通I/Oの別実装、疎FPSのAVX512化、行列積のWinograd–Strassen、Range LISの一括入力、汎用チャンクTreap等も比較しました。安定した改善を得られないものや、FPSと行列の併用時のコード長が増えるものは採用していません。既存の通常版256KiB・軽量版64KiBの検査と、FPS＋Matrixの両プロファイルの検査を維持しています。
