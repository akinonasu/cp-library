# ABC012 D — バスと避けられない運命

[問題](https://atcoder.jp/contests/abc012/tasks/abc012_4) / [提出用コード](abc012_4.cpp)

`abc012_4.cpp` 全体を C++23 として提出できます。既存の `WarshallFloyd<int>`・`TreeDiameter<int>`・`FastInput`・`FastOutput`・`read_unsigned_records` と、その依存コードを展開しています。

入力の辺が多い場合は既存の `read_unsigned_records<3>` でまとめて読み込みます。少ない場合は通常の 32 bit 符号なし整数入力を使います。

無向グラフの最短距離を求め、各頂点の最大距離の最小値を出力します。一般の場合は SIMD 対応の Warshall–Floyd 法を使います。各行の最大値が現在の答え以上になった時点で、その行の走査を打ち切ります。

連結で辺数が頂点数より 1 少なければ木なので、直径を求め、その経路上の頂点を調べます。直径の長さを `D`、片方の端点からの距離を `x` とすると、その頂点の最遠距離は `max(x,D-x)` です。直径から外れた頂点に移ると両端点への最大距離は増えるため、直径上だけで最適な頂点を探せます。

問題の `N <= 300`、正の辺重み `t <= 1000` に対し、最短路は最大でも `299000` で、32 bit 整数で足ります。計算量は一般の場合が時間 O(N³)・空間 O(N²)、木の場合が時間・空間とも O(N) です。非連結グラフは入力に含まれないことを前提としています。

ライブラリ利用部分は次のコードです。リポジトリのルートを include パスに指定してコンパイルできます。

```cpp
#include "graph/warshall_floyd.hpp"
#include "tree/tree_diameter.hpp"
#include "components/fast_io_bulk.hpp"

int main() {
	FastInput in;
	FastOutput out;
	int n = 0, m = 0;
	if (!in.read(n)) return 0;
	in.read(m);
	if (m == n - 1) {
		TreeDiameter<int> tree(n);
		std::vector<std::vector<std::pair<int, int>>> graph(n);
		for (int i = 0; i < m; ++i) {
			std::uint32_t a = 0, b = 0, t = 0;
			in.read(a); in.read(b); in.read(t);
			--a; --b;
			tree.add_edge(a, b, t);
			graph[a].emplace_back(b, t);
			graph[b].emplace_back(a, t);
		}
		auto result = tree.solve();
		int prefix = 0, answer = result.distance;
		for (std::size_t i = 0; i < result.path.size(); ++i) {
			answer = std::min(answer, std::max(prefix, result.distance - prefix));
			if (i + 1 < result.path.size())
				for (auto [to, weight] : graph[result.path[i]])
					if (to == result.path[i + 1]) { prefix += weight; break; }
		}
		out.println(answer);
	} else {
		WarshallFloyd<int> graph(n);
		auto add = [&](std::uint32_t a, std::uint32_t b, std::uint32_t t) {
			graph.add_edge(int(a - 1), int(b - 1), int(t));
			graph.add_edge(int(b - 1), int(a - 1), int(t));
		};
		if (m >= 1024) read_unsigned_records<3>(in, std::size_t(m), add);
		else for (int i = 0; i < m; ++i) {
			std::uint32_t a = 0, b = 0, t = 0;
			in.read(a); in.read(b); in.read(t);
			add(a, b, t);
		}
		graph.solve();
		int answer = graph.infinity();
		for (int i = 0; i < n; ++i) {
			int eccentricity = 0;
			for (int j = 0; j < n && eccentricity < answer; ++j)
				eccentricity = std::max(eccentricity, graph(i, j));
			answer = std::min(answer, eccentricity);
		}
		out.println(answer);
	}
}
```
