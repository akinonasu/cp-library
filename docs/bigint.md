```cpp
#include "lib/math/bigint.hpp"
#include <iostream>

BigInt a("123456789012345678901234567890"), b = 12345;
auto [q, r] = divmod(a, b);
std::cout << a * b << '\n';
std::string s = a.str();
auto p = pow(b, 100);
```

| 操作 | 内容・返り値 |
| --- | --- |
| `BigInt()` / `BigInt(x)` / `BigInt(s)` | 0／整数／十進文字列から構築 |
| `a.str()` | 十進文字列を返す |
| `a.sign()` | 負・0・正に対して -1・0・1 を返す |
| `static_cast<bool>(a)` | 0 でないか |
| `static_cast<T>(a)` | 整数型へ変換。値が `T` に収まること |
| `+a` / `-a` / `abs(a)` | 単項符号／絶対値 |
| `a + b` / `a - b` / `a * b` | 加算／減算／乗算。整数との演算にも対応 |
| `a / b` / `a % b` / `divmod(a,b)` | 商／余り／その組。`b != 0` |
| `a += b` / `a -= b` / `a *= b` / `a /= b` / `a %= b` | 演算結果を代入 |
| `++a` / `a++` / `--a` / `a--` | 1 を加算／減算 |
| `a == b` / `a != b` / `a < b` / `a <= b` / `a > b` / `a >= b` | 整数として比較 |
| `pow(a,k)` | 非負整数乗。`k` は `std::uint64_t` |
| `a.decimal_capacity()` | 十進出力に十分なバッファサイズ |
| `a.to_chars(out)` | バッファへ十進出力し、末尾の次のポインタを返す。終端文字は付けない |
| `in >> a` / `out << a` | 十進整数のストリーム入出力 |

`BigInt` は符号付き整数です。整数型・十進文字列から構築でき、四則演算・剰余・比較・複合代入・`++`・`--`・`abs`・ストリーム入出力に対応します。整数型への変換は `static_cast<T>(a)` です。

`divmod(a, b)` は商・余りを同時に返します。除算は 0 方向への切り捨て、余りの符号は被除数に従います。`pow(a, k)` の `k` は `uint64_t` です。

`std::cin >> a` は空白と省略可能な符号に続く十進数字を読み、数字以外の文字をストリームに残します。例えば `123.45` からは `123` を読み、次の文字は `.` になります。数字を読めなければ値を `0` にして `failbit` を立てます。先頭の空白を読み飛ばす段階で EOF などにより失敗した場合は、値を変更しません。

`components/fast_io.hpp` の `FastInput`・`FastOutput` で一時文字列を減らして入出力できます。自前のバッファへ書く場合は `decimal_capacity()` バイトを確保し、`to_chars(char*)` の戻り値を終端としてください。終端文字は付加しません。

桁数を $$n$$、乗算の時間を $$M(n)$$ として、構築・十進変換・加減算は $$O(n)$$、比較は最悪 $$O(n)$$、乗算は筆算・Karatsuba・NTT を切り替えます。NTT の変換長が $$2^{23}$$ 以下なら $$M(n)=O(n\log n)$$、それを超える場合は分割して計算します。被除数・除数の桁数を $$n\ge m$$ として、除算・剰余は筆算で $$O(nm)$$、逆数法で $$O(\frac{n}{m}M(m))$$ です。`pow` は結果の桁数を $$n$$ として $$O(M(n)\log k)$$、空間は $$O(n)$$ です。
