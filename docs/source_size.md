---
title: "サイズ制限と提出方法"
---

| サイト | 掲載するライブラリ |
| --- | --- |
| [全体サイト（256 KiB向け）](https://qandori.github.io/cp-library/) | 従来の高速実装を全て掲載。64 KiBを超えるものも含む |
| [軽量版サイト（64 KiB）](https://qandori.github.io/cp-library/lightweight/) | 同じ分類・項目順で、65,536 bytes以内の実装を案内。未提供の項目は高速実装へリンク |

両サイトの分類・項目順と機能ごとのURLを揃えています。例えば形式的冪級数は、全体サイトの `fps/fps.hpp.html` と軽量版サイトの `lightweight/fps/fps.hpp.html` から参照できます。Taylor shift・Bostan–Mori・線形漸化式・多点評価・補間も、それぞれ同じ位置にあります。

実装が異なる場合は「高速実装」「軽量実装」と表示し、「軽量実装はこちら」「高速実装はこちら」のリンクで相互に移動できます。**APIやinclude先が異なる場合があるため、移動先の使用例を確認してください。** FPSの軽量実装は `light_fps` と `light_fps_algorithms` を使います。実装が共通の項目は同じソース・APIです。

軽量実装がない項目も一覧の同じ位置に残し、「軽量実装なし」と明記して高速実装へリンクします。全体サイトの既存URLと、従来の `fps_light` などのページも引き続き利用できます。

サイズはUTF-8のバイト数です。1 KiBは1,024 bytesなので、64 KiBは65,536 bytes、256 KiBは262,144 bytesです。
ヘッダー本体だけでなく、依存を全て展開した `Bundle` と、コピー時に付く参照URLのコメント行を含めて測定します。
軽量版では最初から展開コードを表示し、「展開済みをコピー」は常に依存込みのコードをコピーします。
実際のコピー文字列もブラウザで測定し、64 KiBを超える場合はコピーを止めます。

**制限を確認する対象は、最終的に提出するソース全体です。**
ライブラリ単体が収まっていても、解答本体・入出力・他のライブラリを追加すると上限を超える場合があります。
展開時に共通の依存は一度だけ出力されるので、単体サイズの単純な合計とは一致しません。

```sh
oj-bundle -I . a.cpp > submission.cpp
python3 tools/check_source_size.py submission.cpp --limit 64
```

依存の展開は通常の `oj-bundle` を使います。FPS は短縮済み配布ヘッダーを同梱しているため、展開後の追加圧縮は不要です。[提出コードの生成](bundle.md)も参照してください。

```sh
oj-bundle -I . a.cpp > submission.cpp
python3 tools/check_source_size.py submission.cpp --limit 256
```

`check_source_size.py` は提出ファイルそのもののサイズを確認します。`--limit 64` または `--limit 256` を指定し、上限以下なら残りのバイト数を表示し、超過した場合は終了コード1を返します。改行コードやBOMもバイト数に含まれます。

サイトでも通常の依存展開だけを行います。FPSには通常版のほかに [軽量FPS](fps_light.md) と [軽量FPSの各種演算](fps_light_algorithms.md) があります。用途に合うAPIを選んでください。
最終的な提出コードでコンパイル・テストを行ってください。

掲載する版とサイズはページ生成時に自動で更新し、CIでも一覧・説明・コピー対象のサイズの対応を検証します。
64 KiBを超えた実装は軽量版のコピー対象から外れ、一覧には高速実装へのリンクを残します。
