[個数指定の部分和集合](fixed_size_subset_sum.md)の内部部品です。通常は `math/fixed_size_subset_sum.hpp` を include します。

$$\displaystyle F(x)=\sum_{a\in S}x^a$$ の順変換から、$$F(x^j)$$ の各周波数での値を添字の置換で取得します。各周波数で Newton の恒等式 $$\displaystyle i e_i=\sum_{j=1}^{i}(-1)^{j-1}e_{i-j}F(x^j)$$ を計算し、$$e_K$$ だけを逆変換します。$$e_K$$ の係数は、異なる要素を $$K$$ 個選ぶ方法の個数です。逆変換後の共通の非ゼロ定数倍は、存在判定には影響しません。

一つの和を作る選び方が $$c$$ 通りなら、そのそれぞれから一要素を除いた集合は合計 $$Kc$$ 個あり、同じ $$K-1$$ 要素の集合は二度現れません。残りの一要素が和から一意に決まるためです。したがって $$\displaystyle c\leq\left\lfloor\frac{\binom m{K-1}}K\right\rfloor$$ です。

まだ余りが 0 の和だけについて、候補になれる要素の個数から上限を絞ります。和を $$s$$、集合全体で小さい方・大きい方から $$K-1$$ 個の和をそれぞれ $$A,B$$ とすると、選ばれる各要素は $$[s-B,s-A]$$ に入ります。この区間内の要素数を先ほどの上限に代入し、使用した素数の積より小さくなれば追加の変換は不要です。

いずれも長さ $$2^{23}$$ の NTT に対応します。係数上限と素数の積は、32 bit 桁の整数配列で厳密に比較します。NTT は [共通部品](ntt_mod.md)を使い、対応する x86 CPU では AVX2、それ以外ではスカラー経路を使います。

周波数の数を $$L$$ とすると、素数一つにつき $$O(L(\log L+K^2))$$ 時間、$$O(L+K)$$ 空間です。
