[個数指定の部分和集合](fixed_size_subset_sum.md)の内部部品です。集合からちょうど $$K$$ 個の異なる要素を選んで作れる和を求めます。通常は `math/fixed_size_subset_sum.hpp` を include してください。入力条件・返り値は公開ページと同じです。

公開ページの個数上限の判定に使う素数は、次の 10 個です。必要な個数の素数を用い、それらの積が選び方の個数の上限を超えるまで計算します。

| 素数 |
| --- |
| 998244353 |
| 2130706433 |
| 2113929217 |
| 2088763393 |
| 2013265921 |
| 1811939329 |
| 1711276033 |
| 1484783617 |
| 1300234241 |
| 1224736769 |

内部の係数列を、必要な和を含む長さまで 0 で埋めて計算します。その長さを $$L$$ とすると、使用する素数一つにつき $$O(L(\log L+K^2))$$ 時間、$$O(L+K)$$ 空間です。変換長は $$2^{23}$$ 以下です。


`fixed_size_subset_sum_detail::wide_sums(values,k)` は、昇順・重複なしの 64 bit 以下の整数列と、`1 <= k <= values.size()` を受け取ります。返り値は `std::vector<long long>` で、選べる和のいずれかが返り値の型に収まらない場合は `std::overflow_error` を送出します。負数と大きな値の差・和を扱えます。公開関数が入力を整えてから呼ぶため、通常は直接使いません。

この操作も公開関数と同じ計算量・空間を使います。元の値に対する計算は固定幅 128 bit 整数で行い、NTT の値域上限・係数上限は変更しません。
