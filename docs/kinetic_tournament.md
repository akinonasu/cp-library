---
title: "Kinetic Tournament (時刻単調・整数)"
documentation_of: //data_structure/segment_tree/kinetic_tournament.hpp
---

直線列 $$f_i(t)=a_it+b_i$$ に対し、時刻を単調に進めながら区間の最小値と、その直線の添字を求めます。直線の一点変更・追加・削除が可能です。添字の個数は構築時に決め、空いている位置への `set` で追加します。問い合わせ時刻の先読みは不要です。

```cpp
#include "lib/data_structure/segment_tree/kinetic_tournament.hpp"

int main() {
	KineticTournament<> tree(3);
	tree.set(0, 2, 1);
	tree.set(1, -1, 4);
	auto first = tree.all_prod();
	assert(first && first->index == 0 && first->value == 1);
	tree.advance(3);
	auto best = tree.prod(0, 2);
	assert(best && best->index == 1 && best->value == 1);
	tree.erase(1);
	assert(tree.all_prod()->index == 0);
	assert(!tree.prod(1, 3));
}
```

`advance(t)` は **絶対時刻** を指定します。経過時間ではありません。現在時刻以上の整数を渡してください。同じ時刻での更新・問い合わせも可能です。初期時刻は既定で 0 ですが、コンストラクタ・`reset`・`build` の第 2 引数で負の時刻も指定できます。`reset`・`build` による再構築では時刻を戻せます。

`set(i,a,b)` は $$a_it+b_i$$ の係数をそのまま設定します。`b` は時刻 0 での切片で、現在時刻での値ではありません。`advance` 後も `get(i)` の係数は変わりません。

`prod(l,r)` は添字の半開区間 `[l,r)`、`all_prod()` は全添字を対象とします。`optional<Result>` を返し、`Result.index` が最適な直線の添字、`Result.value` が現在時刻での値です。値が同じなら **添字が小さい方** を返します。空区間や有効な直線のない区間では `nullopt` です。削除位置に番兵の直線は置かず、全ての係数を使えます。

`KineticTournament<T, true>` は最大値版です。`T` は符号付き 64 bit 以下の整数型で、係数と時刻の両方に使います。既定は `int64_t`、評価型・返り値の型 `R` は 64 bit 係数なら `__int128_t`、それより狭い係数なら `int64_t` です。既定型は係数・時刻の全域で正確に評価できます。第 3 テンプレート引数で返り値の型を指定する場合は、各操作時点で有効な全直線の値が `R` に収まる必要があります。積と加算は広い型で計算してから `R` に変換するため、途中の積が `R` を超えても構いません。

`next_event()` は木の内部で、どれかの部分区間の勝者が次に変わる整数時刻です。全体の最適な直線がその時刻に変わるとは限りません。表現できる将来の時刻で内部イベントがなければ `nullopt` です。通常の利用では呼ぶ必要はなく、`advance` に任意の将来時刻を渡せます。間にあるイベントを一つずつ進める必要もありません。

| 操作 | 内容・返り値 | 計算量 |
| --- | --- | --- |
| `KineticTournament(n = 0,t = 0)` | 長さ `n` の全位置を空にして、初期時刻 `t` で構築 | $$O(n)$$ |
| `KineticTournament(lines,t = 0)` | `vector<Line>` の全直線を有効にして構築。`Line` は `{a,b}` | $$O(n)$$ |
| `reset(n,t = 0)` | 長さ・初期時刻を指定し、全位置を空にして再構築 | 新旧の長さの合計に対し $$O(n)$$ |
| `build(lines,t = 0)` | 直線列・初期時刻を指定して再構築 | 新旧の長さの合計に対し $$O(n)$$ |
| `set(i,a,b)` | 位置 `i` の直線を設定。削除済み・空なら追加 | $$O(\log n)$$ |
| `erase(i)` | 位置 `i` の直線を削除。有効な直線があった場合は true | $$O(\log n)$$、空なら $$O(1)$$ |
| `get(i)` | 位置 `i` の係数を `optional<Line>` で返す。空なら `nullopt` | $$O(1)$$ |
| `advance(t)` | 現在時刻を `t` まで進め、必要な部分だけ勝者を更新 | $$O(1+E_i)$$、最悪 $$O(n)$$ |
| `prod(l,r)` | 添字区間 `[l,r)` の最適な直線と現在値 | $$O(\log n)$$ |
| `all_prod()` | 全添字の最適な直線と現在値 | $$O(1)$$ |
| `next_event()` | 次の内部イベントの整数時刻 | $$O(1)$$ |
| `time()` | 現在の絶対時刻 | $$O(1)$$ |
| `size()` / `active_size()` / `empty()` | 添字の個数 / 有効な直線数 / 有効な直線がないか | $$O(1)$$ |
| `clear()` | 長さと現在時刻を保ち、全直線を削除 | $$O(n)$$ |
| `swap(other)` | 内容を交換 | $$O(1)$$ |
| コピー / ムーブ | 独立した複製 / 内容を移動。ムーブ元は長さ 0・時刻 0 の空の構造 | コピー $$O(n)$$、ムーブ構築 $$O(1)$$ |

`size()` は空いている位置も含み、`empty()` は `active_size() == 0` の意味です。例えば `KineticTournament<>(10)` は `size() == 10`、`empty() == true` です。添字には `0 <= i < size()` を渡します。再構築後は、それ以前の添字の内容は残りません。

各内部頂点に子の勝者と証明の失効時刻を持ち、失効した部分だけをまとめて計算し直します。浮動小数点・優先度付きキューは使いません。評価値同士の差を取らず係数の差から交差時刻を計算するため、64 bit 全域の係数・時刻でも差のオーバーフローを避けます。

$$n$$ を長さ、$$E_i$$ を `advance` で再計算する内部頂点数とします。空間と構築は $$O(n)$$、点更新・削除・区間問い合わせは $$O(\log n)$$ です。`advance` はイベントがなければ $$O(1)$$、まとめて多くの勝者が変わる場合は $$O(n)$$ になり得ます。直線の変更・削除を行わない区間では、$$q$$ 回の時刻の進行にかかる合計時間は $$O(q+n\log^2 n)$$ です。任意の点更新・削除を含む場合はイベント数に依存し、各進行を常に $$O(\log^2 n)$$ と保証するものではありません。
