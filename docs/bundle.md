---
title: "提出コードの生成とサイズ上限"
---

通常の `oj-bundle` で依存ヘッダーを展開します。専用の提出用スクリプトや、展開後の追加圧縮は不要です。

```sh
oj-bundle -I . a.cpp > submit.cpp
wc -c submit.cpp
```

必要な演算の公開ヘッダーを include してください。共通する依存は一度だけ展開されます。

通常版は **256 KiB = 262,144 bytes 未満**、軽量版は **64 KiB = 65,536 bytes 未満**の提出に向けた構成です。

多項式演算を扱う通常版 FPS のヘッダーを複数併用すると、合成・多点評価などの専用実装が加わるため、単体での上限を超える場合があります。解答本体や他のライブラリも含めた最終ソースのサイズを確認してください。

Web サイトの **Bundle** からも依存ヘッダーを展開したコードをコピーできます。

64 KiB 制限では [軽量版 FPS](https://qandori.github.io/cp-library/fps/fps_light.hpp.html) を使います。解答部分や他のライブラリを追加した最終ソースの大きさは `wc -c` で確認してください。
