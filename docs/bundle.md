---
title: "提出コードの生成とサイズ上限"
---

通常の `oj-bundle` で依存ヘッダーを展開します。専用の提出用スクリプトや、展開後の追加圧縮は不要です。

```sh
oj-bundle -I . a.cpp > submit.cpp
wc -c submit.cpp
```

高速 FPS・軽量 FPS ともに、通常の C++ のヘッダーを保存しています。高速実装は必要な演算の公開ヘッダーを include し、共通する依存は一度だけ展開されます。短縮用の辞書マクロや専用の配布コード生成は使いません。

通常版の各 FPS 公開ヘッダーについて、その公開 API の使用例と基本の `FastInput`・`FastOutput` を含む展開コードが **256 KiB = 262,144 bytes 未満**になることを検査します。軽量版は全 FPS 演算と同じ入出力を併用して **64 KiB = 65,536 bytes 未満**になることを検査します。検査には後処理のない `oj-bundle` の出力を使います。

複数の通常版 FPS ヘッダーを併用すると、合成・多点評価などの専用実装が加わるため、単体での上限を超える場合があります。解答本体や他のライブラリも含めた最終ソースのサイズを確認してください。

Web サイトの **Bundle** も依存ヘッダーの展開だけを行います。サイト生成時には参照 URL を付けた Copy のサイズも検査します。上限を超えたコードを、自動圧縮して表示することはありません。

64 KiB 制限では [軽量版 FPS](https://qandori.github.io/cp-library/fps/fps_light.hpp.html) を使います。解答部分や他のライブラリを追加した最終ソースの大きさは `wc -c` で確認してください。
